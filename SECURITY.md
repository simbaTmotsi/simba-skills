# Security

These skills run inside AI agents with access to servers, databases and settings, so security reports are taken seriously.

## Reporting

Report privately through GitHub: **Security** tab, then **Report a vulnerability**. Please do not open a public issue.

Include which skill or script, what an attacker or a mistaken agent could do, and how to reproduce it.

## What counts

- A skill or script that can run something destructive or outward-facing without asking.
- A way to make a skill leak secrets, run downloaded code, or follow hidden instructions.
- A merged change that weakens any promise in [SCOPE.md](./SCOPE.md).

You will get a reply within a week. Fixes ship as a new plugin version, which auto-update delivers to installed users.
